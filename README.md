# A Wheelchair Experience @ Temasek Shophouse

A standalone, self-guided wheelchair tour iteration with three activities, illustrated steps, reflections, and participant feedback.

## Open locally

Open `index.html` in a modern browser. The narration uses the browser's built-in speech synthesis and prefers an English feminine voice when one is available on the device.

## Files

- `index.html` contains the tour and its interactions.
- The image files in this folder are used by the activity guide and feedback screen.

This iteration is maintained separately from the main project repository.
